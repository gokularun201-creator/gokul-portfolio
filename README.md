# 🛡️ Gokul.R - Cybersecurity Portfolio

A stunning cybersecurity-themed personal portfolio website featuring matrix rain effects, terminal aesthetics, glitch animations, and interactive UI.

## ✨ Features

- **Matrix Rain Background** - Classic hacker aesthetic
- **Terminal-Style About Section** - Interactive Kali Linux terminal
- **Glitch Text Effects** - Cyberpunk name animation
- **Typing Animation** - Dynamic role display
- **Scroll Reveal Animations** - Smooth entrance effects
- **Animated Skill Bars** - Visual skill representation
- **Floating Particles** - Ambient visual effect
- **Cursor Glow** - Interactive mouse follower
- **Konami Code Easter Egg** - Try ↑↑↓↓←→←→BA
- **Fully Responsive** - Works on all devices
